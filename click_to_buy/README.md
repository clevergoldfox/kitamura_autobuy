# 中古クリック購入ツール

カメラのキタムラネットショップの中古一覧ページで、任意の商品をクリックすると購入確認を表示し、「はい」で購入を実行するツールです。

## 機能

- 起動時に中古一覧ページ（`https://shop.kitamura.jp/ec/list?type=u&limit=100&page=1&sort=update_date`）を表示
- 未ログイン時はログインページにリダイレクトされ、手動ログイン後に再度一覧を表示
- 一覧で商品をクリック → 「本当に購入しますか？」（はい / いいえ）
- 「はい」→ 購入実行。完了時は「正確に購入しました」、失敗時は「購入失敗\nエラー内容：...」を表示
- 通知の「確認」ボタンで中古一覧に戻る

## 必要な環境

- Python 3.8+
- PyQt5
- Playwright（Chromium）

## セットアップ

```bash
cd click_to_buy
pip install -r requirements.txt
playwright install chromium
```

## 実行

```bash
python main.py
```

## 使い方

1. メール・パスワードを入力し「保存」でログイン情報を保存（任意）
2. 「スタート」をクリックしてブラウザを起動
3. 未ログインならログイン後、中古一覧が表示される
4. 一覧で購入したい商品をクリック
5. 「本当に購入しますか？」で「はい」を選択すると購入が開始される
6. 結果表示の「確認」で一覧に戻り、続けて他の商品を選べる
